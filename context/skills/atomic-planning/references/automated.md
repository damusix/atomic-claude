# Automated challenge

Run only on request or when `/autopilot` selects this route. It does not replace spec review or authorize changes to the agreed scope.

1. Define the decision or artifact, the selected method, scope, and evidence available. Dispatch an independent challenger with that brief and no respondent findings. Ask for evidenced objections, assumptions, and questions, including evidence that would change each conclusion.
2. Give a separate respondent the original brief and the challenger's findings. Require a response to each finding with cited evidence, distinguishing accepted issues, refuted claims, and unresolved disputes. Verify checkable claims rather than treating either agent's assertion as proof.
3. Synthesize the evidence and revise the plan only within the user's authorized scope. Escalate decisions about user-facing behavior, business rules, scope, and material tradeoffs to the human; do not let agents decide those on the user's behalf. Report unresolved evidence gaps and stop for decisions that block the plan.

If independent agents are unavailable, report that limitation. Outside Autopilot, offer an interactive challenge. Autopilot can continue with checkable evidence; stop if a blocking question remains.

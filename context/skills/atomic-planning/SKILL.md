---
name: atomic-planning
description: Select and apply an evidence or challenge method when planning, testing a claim, questioning a decision, or reviewing a design through independent lenses.
---

Choose one method for the uncertainty at hand. Load only its reference; direct commands select their named method.

| Uncertainty | Method | Reference |
|---|---|---|
| A factual claim can be checked | Evidence for and against the claim | [evidence.md](references/evidence.md) |
| A decision or its boundaries need clarification | Socratic dialogue with the user | [pressure-test.md](references/pressure-test.md) |
| A written artifact needs independent perspectives | Isolated expert lenses and a contradiction map | [swarm.md](references/swarm.md) |

Recommend one method. Run an automated challenge only when requested or when invoked by `/autopilot`; use [automated.md](references/automated.md). Outside Autopilot, the user can choose interactive dialogue or decline. Keep the mandatory full-spec review separate.

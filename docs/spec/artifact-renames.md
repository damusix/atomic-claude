## Mechanics per artifact kind

**Skills** are source-only. Rename = `git mv skills/<old>/ skills/<new>/`, update the `name:` frontmatter inside `SKILL.md`, update every self-reference in the skill body (e.g. "invoked by /<old>" phrasing), then sweep the repo for references.

**Commands** are rendered. Rename = `git mv templates/commands/<old>.md templates/commands/<new>.md`, `git rm commands/<old>.md` (the orphan rule halts `make render` if a rendered output has no matching template), run `make render` to materialize `commands/<new>.md`, then sweep.

**Embedded bundle**: `make -C atomic bundle` does not prune deleted sources — after each rename, `git rm -r` the stale copy under `atomic/internal/embedded/bundle/` (old skill dir or old command file) before or after regenerating. `manifest.go` is regenerated by the bundle target. Render always runs before bundle.

**Pre-commit hook** (`.githooks/pre-commit`, active via `core.hooksPath`) chains render → bundle → followups automatically when matching paths are staged; the implementer still runs `make render` / `make -C atomic bundle` manually and stages the outputs explicitly so the commit is self-contained.

## Constraints

- `docs/spec/**` files touched during the sweep: update only current-truth body references; `## Change log` AND `## Implementation log` sections are history and must not be rewritten (rule `rules/specs/spec-currency.md`; implementation logs narrate what specific commits did — rewriting them contradicts `git show`).
- Never hand-edit `docs/wiki/*.md` — the signals refresh regenerates them after the loop.
- Old names may legitimately survive in: spec change-log entries, `CHANGELOG.md`, `docs/research/`, `docs/wiki/` (until signals refresh), and `.claude/project/followups/` closed history. Everywhere else, zero occurrences.
- Commit messages: Conventional Commits per the commit-message skill. The branch squashes to one `fix!:` commit at ship (renames of user-touchable commands/skills are breaking; release-please filters `refactor:`).
- No AI bylines anywhere.

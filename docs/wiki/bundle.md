# bundle

## What it does

Template rendering → bundle embedding → install/uninstall into `~/.claude/`. Human-authored markdown in [`templates/commands/`](../../templates/commands) and [`templates/agents/`](../../templates/agents) is rendered by `make render` into [`commands/`](../../commands) and [`agents/`](../../agents); `make bundle` embeds the outputs plus [`skills/`](../../skills), [`output-styles/`](../../output-styles), [`rules/`](../../rules), and [`CLAUDE.md`](../../CLAUDE.md) into the Go binary. `atomic claude install` copies the embedded bundle to `~/.claude/`.

## Artifacts

- `templates/commands/*.md` — 23 per-verb command source files (plus 2 runtime prompt partials under [`templates/commands/_templates/`](../../templates/commands/_templates)). - `templates/agents/*.md` — 5 agent source files. Edit surface for subagent definitions. Mirrors the commands template pattern.
- `templates/shared/*.md` — 23 reusable partials composed via `{{ template "<name>" . }}`. Big command partials: `commit-flow`, `pr-flow`, `merge-flow`, `squash-flow`, `push-flow`. Small command partials: `doc-impact`, `signals-gate`, `base-resolution`, `worktree-cleanup-prompt`, `worktree-setup`, `git-safety`, `staleness-check`, `report-issue-privacy` (defines `report-issue-privacy` — PII/secret redaction + preview-and-confirm gate composed into both `report-issue.md` and `report-issue-with-atomic.md`). Agent partials: `agent-tdd-signals` (TDD + quality-signals steps), `agent-signals-output` (output block format), `agent-shared-rules` (style/git/error-quoting constraints), `agent-search-tooling` (grep/glob/sg tool-selection rule; one-line bridge names code-intel as top search tier when index present), `agent-implementer-workflow` (shared `<workflow>` block for `atomic-implementer.md`, composes `agent-search-tooling` + `agent-tdd-signals` + `agent-code-intel`), `agent-atomic-voice` (response-voice rule injected into all 5 agent templates — instructs subagent to return findings only, no preamble or recap), `agent-code-intel` (`atomic code` verb guidance with graceful degradation contract; composed into `atomic-implementer.md` via `agent-implementer-workflow`, and directly into `atomic-investigator.md`, `atomic-reviewer.md`, and `atomic-wiki-inferrer.md`), `agent-yagni` (Simplicity-first YAGNI 7-step ladder; composed into `atomic-implementer.md`, `atomic-reviewer.md`, `atomic-strategist.md`; kept verbatim in sync with the same ladder in [`CLAUDE.md`](../../CLAUDE.md) Principles block — edit both together).

**Bundle inputs (the distributed artifact set):**

- [`agents/`](../../agents) — 5 subagent definitions (`atomic-*.md`), now rendered outputs. All ship via `agents/atomic-*.md` bundlespec rule.
- [`skills/`](../../skills) — 10 skill directories (`atomic-*/SKILL.md`), including the new [`skills/atomic-bus/SKILL.md`](../../skills/atomic-bus/SKILL.md) (peer messaging between concurrent Claude Code sessions over named rooms). Full directory subtree bundled per `atomic-` prefix dir.

- [`rules/`](../../rules) — 3 path-scoped topic rules (`python/style.md`, `typescript/style.md`, `specs/spec-currency.md`). `specs/spec-currency.md` has `paths: ["docs/spec/**/*.md", "docs/design/**/*.md"]` — auto-loads when touching spec or design files; enforces "body is current truth, change log is history".
- [`CLAUDE.md`](../../CLAUDE.md) — global instructions bundled directly. Installed to `~/.claude/CLAUDE.md`. Atomic-owned content is bounded by `<atomic>...</atomic>` tags; everything outside those tags is user-owned. `atomicblock.go` uses this boundary during install to swap the block in place. `@-ref` lines and the "Where things live" table row now read `@~/.atomic/config.resolved.md`, `@~/.atomic/profile.md`, and `~/.atomic/` (moved from `~/.claude/.atomic/`, issue #150). The `<atomic>` block also carries a new `## Inter-session messaging` section (between the wiki paragraph and `## Code-intel engine`) documenting `atomic bus` peer messaging between concurrent Claude Code sessions.

## CLI code

- [`atomic/internal/bundlespec/`](../../atomic/internal/bundlespec) — pure inclusion predicate functions (`MatchesAgent`, `MatchesSkillDir`, `MatchesOutputStyle`, `MatchesCommand`, `MatchesRule`, `IsClaudeMd`). Single source of truth for all inclusion decisions. Both `bundlemirror` (build-time) and `manifestcheck` (runtime) import this package — changing a predicate here propagates to both.
- [`atomic/internal/bundlemirror/mirror.go`](../../atomic/internal/bundlemirror/mirror.go) — build-time walker. Reads repo root, calls `bundlespec` predicates, copies matching artifacts into [`atomic/internal/embedded/bundle/`](../../atomic/internal/embedded/bundle), writes `manifest.go`. Commands walk is `filepath.WalkDir` (recursive) so [`commands/_templates/`](../../commands/_templates) is included. Called by [`atomic/cmd/bundle-mirror/main.go`](../../atomic/cmd/bundle-mirror/main.go) via `go generate`. Each artifact file is read once during `Enumerate` (bytes stored in `EnumeratedArtifact.Data`); `Run` reuses those bytes for the copy step — no second `os.ReadFile` call. `EnumeratedArtifact` carries `SrcPath` (absolute) and `Data` alongside the existing `Target`/`Kind`/`Hash` fields. First unit tests in `mirror_test.go` cover `Enumerate` and `Run` in isolation.
- [`atomic/internal/embedded/`](../../atomic/internal/embedded) — holds `//go:embed all:bundle` FS (`bundle.go`) and generated `Manifest()` slice (`manifest.go`). `all:` prefix required — without it, [`commands/_templates/`](../../commands/_templates) (underscore prefix) would be silently absent. Never edit `bundle/` or `manifest.go` by hand.
- [`atomic/cmd/bundle-mirror/main.go`](../../atomic/cmd/bundle-mirror/main.go) — build-time entrypoint for `bundlemirror.Run`. Called by `go generate ./...`. Success line written to stdout: `"bundle-mirror: wrote N artifacts to <outDir>"`. Errors go to stderr.
- [`atomic/cmd/render-templates/main.go`](../../atomic/cmd/render-templates/main.go) — build-time entrypoint for `templaterender.Render`. Called by `make render`. Success line written to stdout: `"render-templates: done"`. Errors go to stderr.
- [`atomic/internal/templaterender/`](../../atomic/internal/templaterender) — Go `text/template` renderer. Iterates `renderedKinds = ["commands", "agents"]`; for each kind renders `templates/<kind>/*.md` (using shared partials from [`templates/shared/`](../../templates/shared)) into `<outDir>/<kind>/*.md`. Single shared-partial pool is cloned per file, so all partials (command and agent) are available to any template. Orphan guard: any `<kind>/<name>.md` without a matching `templates/<kind>/<name>.md` halts render with non-zero exit naming both remediation paths (create template OR `rm` output).
- [`atomic/internal/claudeinstall/atomicblock.go`](../../atomic/internal/claudeinstall/atomicblock.go) — `<atomic>...</atomic>` block parser. `atomicBlockBounds` returns byte offsets of the single block (line-anchored tag matching). `replaceAtomicBlock` swaps the block in place, preserving user content outside it byte-for-byte. `atomicBlocksEqual` compares blocks across two files. Ambiguous shapes (no tags, unclosed, multiple blocks) return `!ok`, triggering fallback to the LLM merge path.
- [`atomic/internal/claudeinstall/install.go`](../../atomic/internal/claudeinstall/install.go) — install/update/diff/list verbs. SHA256-based idempotency. Backs up changed files to `~/.atomic/backups/<ts>/` (moved from `~/.claude/.atomic/backups/`, issue #150 — `config.Dir(home)` resolves the atomic-owned state root, independent of `~/.claude`, the artifact-install target). `ActionBlockReplaced` (new kind): CLAUDE.md only — when both on-disk and embedded carry a parseable `<atomic>` block and the blocks differ, `replaceAtomicBlock` swaps the block in place; user content outside the block is preserved byte-for-byte; no proposed-file is written. `ActionMergeRequired` fires only when no parseable block exists (pre-tag installs, malformed tags); the install output directs the user to run `atomic prompt claude-merge` in a Claude Code session. Pre-creates `config.resolved.md` on every `Apply`. Calls `profile.CaptureEnv` + `profile.RenderStub` to write `~/.atomic/profile.md` on first install (skips if file already exists); `ProfileNudge` printed to stdout also reads `~/.atomic/profile.md`. `readPatchedEmbedded(a embedded.Artifact, overrides map[string]config.AgentOverride)` reads an embedded artifact's bytes via `fs.ReadFile(embedded.FS, a.Source)` and applies `patchAgentContent` (a no-op for non-agent artifacts, nil overrides, or an entry with both `Model` and `Effort` empty); `planArtifact` and `applyAction` both call this helper for their read+patch step. `patchAgentContent` patches `model:` and `effort:` frontmatter keys independently (an effort-only override leaves `model:` untouched and vice versa) via the shared `setOrAppendKey` helper, which sets an existing key or appends it while preserving source order of every other key. `Diff` calls `loadAgentOverrides(targetDir)` once and passes it through `readPatchedEmbedded` for every artifact before comparing SHA256 hashes, so an agent artifact installed with a configured `[claude.agents.<name>]` model/effort override is compared against the same patched content `Apply` would have written rather than the raw embedded bytes — this fixes a false-positive `DiffDiffer` report for override-customized agent installs (issue #129). `ReapplyAgents(targetDir, home) (changed []string, installed int, err error)` re-patches only agent artifacts already present on disk at `targetDir` with the config domain's current `[claude.agents]` overrides — it never performs a first-time install (an absent agent file is left untouched, `installed` still counts it as 0). Built by calling `Plan` then filtering to `Artifact.Kind == "agent"` entries that are not `ActionInstalled` (skips first-time-install candidates), applying only the `ActionUpdated` subset via the normal `Apply` path (same backup behavior as install/update), and returning the applied artifacts' basenames (minus `.md`) as `changed`. Called from `atomic config agents` (config domain) via the `ApplyAgentsHook` seam.
- [`atomic/internal/claudeinstall/reapply_agents_test.go`](../../atomic/internal/claudeinstall/reapply_agents_test.go) (new) — `TestReapplyAgents_PatchesInstalledAgent` (patches an installed agent's frontmatter, confirms an uninstalled sibling agent is not created), `TestReapplyAgents_SkipsAbsentAgent` (no agents installed → `installed == 0`, nothing created), `TestReapplyAgents_IdempotentOnSecondCall` (a second call with no config change reports empty `changed`).
- [`atomic/internal/claudeinstall/uninstall.go`](../../atomic/internal/claudeinstall/uninstall.go) — `BuildUninstallPlan` resolves the pre-install snapshot/backup root via `config.Dir(home)` (→ `~/.atomic`, issue #150 — dropped a `filepath.Join(targetDir, ".atomic")` literal).
- [`atomic/internal/profile/profile.go`](../../atomic/internal/profile/profile.go) — `CaptureEnv()` reads `git config --global user.name/user.email` + `runtime.GOOS/GOARCH/NumCPU`. `RenderStub(Env)` returns the initial `profile.md` content with six sections tagged `<stable>`, `<volatile>`, or `<deterministic>`. Called by `claudeinstall` at install time and by [`atomic/internal/claudeinstall/uninstall.go`](../../atomic/internal/claudeinstall/uninstall.go) (uninstall removes profile.md). Git failures produce empty strings — install is not aborted.
- [`atomic/internal/manifestcheck/`](../../atomic/internal/manifestcheck) — runtime bundle validator. Calls `bundlespec` predicates to verify the embedded manifest matches expectations. Used by doctor check index 5 (`manifest`).

**Pre-commit hook ([`.githooks/pre-commit`](../../.githooks/pre-commit))** — three-stage pipeline:

1. If [`templates/`](../../templates) files staged → `make render`, re-stages [`commands/`](../../commands) **and** [`agents/`](../../agents) outputs.
2. If any source artifact staged ([`agents/`](../../agents), [`commands/`](../../commands), [`skills/`](../../skills), [`output-styles/`](../../output-styles), [`rules/`](../../rules), [`CLAUDE.md`](../../CLAUDE.md)) → `make bundle`, re-stages [`atomic/internal/embedded/bundle/`](../../atomic/internal/embedded/bundle) and `manifest.go`.
3. If [`.claude/project/followups/`](../followups) files staged (excluding INDEX.md) → `atomic followups render`, re-stages INDEX.md.

Render fires before bundle (bundle reads what render wrote). Install via `make hooks`; uninstall via `make hooks-uninstall`.

## Coupling

- **→ signals**: [`commands/`](../../commands) output is read by `bundlemirror` downstream of the template render step. Pipeline order is load-bearing: `make render` must precede `make bundle`.
- **→ workflow**: ship verb commands (in [`commands/`](../../commands)) are rendered from [`templates/commands/`](../../templates/commands) + [`templates/shared/`](../../templates/shared) partials. Editing any ship verb flow requires editing the template source, not the rendered output.
- **→ doctor**: [`atomic/internal/manifestcheck/`](../../atomic/internal/manifestcheck) (used by doctor check 5) imports `bundlespec`. Changing a bundlespec predicate affects which items fail the manifest check.
- **→ config**: `claudeinstall.Apply` pre-creates `~/.atomic/config.resolved.md`. Config domain owns the content of that file; bundle domain writes it as a side effect of install.
- **→ config**: `install.go` and `uninstall.go` both call `config.Dir(home)` / `config.TOMLPath` / `config.ProfilePath` (config domain, [`atomic/internal/config/paths.go`](../../atomic/internal/config/paths.go)) for the `~/.atomic` state root — issue #150's two-root split (state root vs. `~/.claude` artifact-install target) is enforced by that package, not duplicated here.
- **→ docs-meta**: [`CLAUDE.md`](../../CLAUDE.md) (bundle input) must stay synchronized with [`CLAUDE.md`](../../CLAUDE.md) (the committed project instructions). Adding a new artifact requires updating both.
- **→ doctor**: [`atomic/internal/profile/`](../../atomic/internal/profile) is exercised by doctor category 10 (`checks_profile.go`). Changes to `CaptureEnv` or `RenderStub` (profile package, this domain) affect what doctor checks as "profile wired".
- **→ doctor**: `claudeinstall.Diff` (this domain) is called by `checks_install.go` (doctor category 1, `install` check) to detect drift between the embedded bundle and the on-disk install; `Diff` now applies `[claude.agents.<name>]` model/effort overrides before comparing, so an override-customized install ([`atomic/internal/config`](../../atomic/internal/config) `Config.Claude.Agents`, config domain) no longer produces a false-positive WARN. The same `Diff`/`readPatchedEmbedded` path also gives the doctor install check a genuine-drift signal for free: a configured override not yet reflected on disk (e.g. before `ReapplyAgents` or `atomic claude install` runs) is a real SHA mismatch → WARN, locked by `TestCheckInstall_agentOverrideDrift_detectAndRepair` in [`atomic/internal/doctor/checks_install_test.go`](../../atomic/internal/doctor/checks_install_test.go) (doctor domain) — no new check was added for this.
- **→ config**: `ReapplyAgents` is wired to the config domain's `ApplyAgentsHook` package-var seam by [`atomic/cmd/atomic/main.go`](../../atomic/cmd/atomic/main.go)'s `init()`, since `internal/config` cannot import `internal/claudeinstall` (this domain) without cycling — `main.go` is the only package importing both, so it closes the loop. `ReapplyAgents` resolves its target via `claudeinstall.ResolveTarget("~/.claude")` — a custom `--target` install directory is invisible to the [`agents`](../../agents) verb and is not auto-applied.
